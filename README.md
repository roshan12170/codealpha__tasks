# codealpha__tasks
Car Price Prediction project uses Machin learning model to predict the car price based on

- Year
- Fuel_Type
- Driven_kms
- Selling_type
- Transmission

## Technology used
- Python
- Pandas
- Numpy
- Scikit-learn
- Matplotlib
## Project Workflow
1. load the car dataset.
2. Perform data preprocessing.
3. Split the data into training and testing part
4. Train the model and perform test
5. Evaluate model using linear Rigression and RandomForest Rigression
6. Pridict the car price

## Output 
Model predict the car price (Selling Price) .
